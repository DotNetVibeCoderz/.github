# Summary of Projects

## CuteDB
**CuteDB** is a simple, in-memory embedded database for .NET applications designed to be lightweight and easy to use for small projects or prototyping needs. It supports CRUD operations, LINQ queries, and simple SQL commands.

## MemSharp
**MemSharp** is an in-memory database prototype built using C# .NET, mimicking basic Redis functionality with TCP Client-Server architecture support and SQL-like Queries. It allows for various data structures and operations.

## Maze 3D
**Maze 3D** is a retro-style maze game inspired by classic raycasting games. It features a 3D raycasting engine, procedural generation, and progressive difficulty.

## Minesweeper
A classic **Minesweeper** game recreated using C# and Windows Forms, featuring three difficulty levels, classic mechanics, and an interactive UI.

## SnakeGamePixel
A classic Snake game built using C# and Windows Forms, featuring a dynamic challenge with increasing speed and obstacles.

## Space Shooter
A classic space shooter arcade game developed using C# WinForms, featuring multiple levels, boss fights, and various enemy types.

## Tamagochi
**Tamagochi** is a cute and interactive pixel-art style digital pet simulator. It features a lifecycle, auto-save, and various interactions to take care of the pet.

## Nerve
**Nerve** is a lightweight, fast, and simple in-memory messaging library for .NET applications, implementing the Publish-Subscribe pattern for easy communication between components.

## SocketSignal
**SocketSignal** is a real-time two-way communication library based on pure WebSocket in .NET, allowing clients and servers to call methods in real-time.

## Compressor
A simple File Explorer application built with Avalonia UI and .NET, featuring folder navigation, file management, and archive compression/extraction.

## D3Net
**D3Net** is a cross-platform data visualization library inspired by D3.js, providing various chart types with smooth animations and modern graphics.

## Image Explorer
**Image Explorer** is a lightweight and fast cross-platform desktop application for exploring, viewing, and editing images, featuring an integrated file explorer and advanced viewer capabilities.

## PCInfo
**PCInfo** is a modern, cross-platform desktop application that provides detailed specifications about your computer's hardware, operating system, and network configurations.

## WeatherApp
**WeatherApp** is a simple cross-platform desktop weather app that fetches real-time weather data from Open-Meteo and displays various weather information for selected cities.

## Conclusion
These projects showcase various applications built using C# and .NET, demonstrating capabilities in database management, game development, UI design, and data visualization.
